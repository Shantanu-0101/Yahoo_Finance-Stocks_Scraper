# Yahoo_Finance-Stocks_Scraper
A high-performance tool collecting real-time market data for analysis

## Key Features:
• Scrapes historical prices, fundamentals (P/E, EPS), and real-time metrics
• Implements proxy rotation and randomized delays to avoid blocks
• Generates analysis-ready CSV datasets

## Tech Stack: 
• Python 
• Selenium
• BeautifulSoup
• Pandas
• Proxy Rotation
